Sobre o Projeto

Um sistema inteligente voltado para inclusão, bem-estar emocional e apoio educacional.

🎯

Descrição

O Diário de Bordo da Inclusão é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), com foco no acompanhamento emocional de alunos. A proposta utiliza tecnologia de ponta para coletar e analisar dados emocionais, auxiliando educadores na tomada de decisões estratégicas.

🚀

Objetivo

Promover a verdadeira inclusão e oferecer uma ferramenta que permita identificar padrões emocionais, contribuindo ativamente para um ambiente educacional mais acolhedor, humanizado e eficiente.

Tecnologias Utilizadas

Python Django PostgreSQL HTML5 CSS3 JavaScript APIs REST NLP (IA)
